## Unicode

- bottom **`„`** quotation marks `[Ctrl] + [Shift] + [U]`, then type `201e` and press `[Enter]`.
- top **`“`** quotation marks `[Ctrl] + [Shift] + [U]`, then type `201c` and press `[Enter]`.
